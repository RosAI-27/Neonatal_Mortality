# Data

This directory contains the prepared analytical dataset used by the project.

## Dataset

- **Source:** EDS/DHS Cameroon 2018
- **File:** `neonatal_mortality_data.csv`
- **Separator:** `;`
- **Target variable:** `neonatal_mort`
- **Observations:** 33,988
- **Variables:** 15

The Streamlit application also supports uploading a compatible CSV through its sidebar.

The original DHS `.SAV` source file is not included in this repository. The included CSV is a prepared analytical dataset derived from the survey data.
